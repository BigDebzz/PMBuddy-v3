# PM Buddy Brand Guidelines

Decisions made once. `DESIGN.md` turns these values into rules.

## Personality
Warm, friendly and calm. A patient guide for people who are not project managers. It never feels corporate, technical or intimidating.

## Colours

| Name | Hex | Use |
|------|-----|-----|
| River Blue | `#35709A` | Primary: main buttons, links, active states |
| River Blue Deep | `#2B5F85` | Hover and pressed state of primary, strong emphasis text |
| River Mist | `#E8F1F6` | Light blue tint: selected rows, info panels, soft highlights |
| River Border | `#BCD6E5` | Border for blue-tinted panels |
| Canvas | `#FAF8F5` | Page background (warm off-white) |
| Surface | `#FFFFFF` | Cards, inputs, modals |
| Stone Border | `#E7E2DA` | Default borders and dividers |
| Ink | `#2B2A28` | Headings and body text |
| Muted | `#6B665F` | Secondary text, captions, labels |
| Faint | `#8A847B` | Placeholders, disabled, decorative only. Never for readable text |
| Success | `#15803D` / tint `#F0FDF4` | Done, healthy, on track |
| Warning | `#D97706` / tint `#FFFBEB` | At risk, due soon |
| Danger | `#DC2626` / tint `#FEF2F2` | Overdue, blocked, errors, delete |

The old purple (`#7C3AED`) is retired. The old black buttons (`#0A0A0A`) become River Blue.

## Typography
- Font: **Plus Jakarta Sans** (already in use), weights 400, 500, 600, 700. Fallback: system sans-serif.

| Role | Size | Line height | Weight |
|------|------|-------------|--------|
| Caption | 12px | 1.4 | 500 |
| Body small | 14px | 1.5 | 400 |
| Body | 16px | 1.6 | 400 |
| Heading 3 | 20px | 1.3 | 700 |
| Heading 2 | 26px | 1.25 | 700 |
| Heading 1 | 34px (28px on phones) | 1.2 | 700 |

## Spacing
Base unit 4px. Scale: 4, 8, 12, 16, 24, 32, 48, 64.

## Shape
Soft and rounded. Buttons and inputs 10px, cards 16px, modals 20px, tags and badges fully round.
